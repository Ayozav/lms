# Явные договорённости

Несмотря на структуру в данный момент (относительный монолит), считается, 
что students-service отвечает за всю LMS систему, быть может кроме Сервиса "Перо".

1. Все методы, приходящие на Kafka - это методы типа POST/PUT/DELETE.
2. Все методы типа GET - отражают прямой запрос в БД, без промежуточной линии
3. Консьюмер (обработчик) скармливает всё БД напрямую
4. Продюсер (завод событий) сначала проверяет входные значения, а затем - отдаёт консьюмерам.
5. КАФКА И СОБЫТИЯ В НЕЙ НЕ ЗАНИМАЮТСЯ ПРОВЕРКОЙ АВТОРИЗАЦИИ И АУТЕНТИФИКАЦИИ, 
этим должен заниматься Javalin в предварительно обработчике.
