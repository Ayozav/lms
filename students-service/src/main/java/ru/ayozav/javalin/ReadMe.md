# Договорённости

1. `answers` отдаёт все возможные ответы, выставляет статус `ctx`'у. 
    - Никаких `ctx.status(200)` внутри контроллера.
2. `controllers` проверяет все входные значения и либо отдаёт всё Кафке, либо рисует запрос к БД напрямую. 
   - Никаких `parsePositiveInt(obj)` внутри answers.
3. `exceptions` бросает все виды исключения, которые могут быть. 
   - Никаких `throw new RuntimeException` или чего-то такого.
